# 1.1.25 敵対対象の引継ぎ・再捕捉

利用者報告：「他にも敵対が普通のプレイヤーと異なる挙動をしそうなら確認・修正」「一回ターゲットが外れたらそれ以降攻撃してこないモブがいる」。報告対象のモブ名・具体的な再現操作は不明。

## 確認した経路と修正

- 1.1.24の対象判定は `Monster || Phantom`。Paper 26.2 APIで `Enemy` だが `Monster` ではないガスト、スライム、マグマキューブ、シュルカー、ホグリンも対象にする。通常のクモの既存の敵対引継ぎを維持し、洞窟グモは通常の敵対モブとして扱う。
- 開始時に既に本人を狙っている `Mob` は、中立モブも含め本体へ切り替える。継続中の追跡記録も通常のクモ限定から `Mob` に拡張する。他の相手を狙い始めた個体のターゲットは奪わない。
- Brainを使用するモブは、通常のターゲットフィールドと `ATTACK_TARGET` の両方を同期する。片側に本体が残っていてもBrainが忘れた場合は復元する。既存の `ANGRY_AT`、NeutralMobの永続敵対参照、ウォーデンの怒りは本人と本体の間で引き継ぐ。有効時間を延長したり、無関係な相手への怒りを書き換えたりしない。
- 対象を失った中立モブは、今回の本人／本体へのネイティブの怒りが続いている場合に再捕捉する。怒りが切れたら追跡記録を解除する。通常のクモは以前の引継ぎ仕様を維持する。
- 新たな捕捉にはネイティブの戦闘対象判定を使用し、追跡距離属性、視線・透明化・攻撃可能性の判定を通す。Brainの鎮静・逃避・鑑賞中も強制捕捉しない。クリエイティブ／スペクテイターの敵対除外、本来の無敵状態・透明状態も本体に反映する。
- スライム類の通常のプレイヤー接触処理はMannequinには発生しないため、本体近くでネイティブの接触攻撃処理を呼ぶ。大きさ、攻撃範囲、視線、威力の判定と通常のダメージイベントを利用する。ダメージでFreecamが終了したら以降の本体処理を打ち切る。
- 幽体の移動などを発生源にする `GenericGameEvent` を停止し、幽体の位置からの振動が本体の位置とは別にAIへ伝わることを防ぐ。
- 本体から通常復帰した場合は追跡対象を本人へ引き継ぐ。外部TPでの終了時は追跡先を移動先へ付け替えない。
- ターゲット変更は一度イベントに通し、他プラグインによるキャンセル・変更を両方の保存先に反映する。ネイティブの呼出しに失敗した場合は操作ごとに一度警告し、独自の怒り時間・ダメージ値を作らない。

## 対象ごとの検証範囲

| 対象 | 今回の扱い | 残る確認 |
| --- | --- | --- |
| ファントム・通常の敵対モブ・洞窟グモ | 捕捉・再捕捉、通常復帰時の引継ぎ | 実際の移動・射撃・命中 |
| ガスト・スライム類・シュルカー・成体ホグリン | 分類漏れを解消し捕捉・再捕捉。スライム類は接触攻撃経路も補う | 固有AIによる飛行・逃避・攻撃周期 |
| オオカミ・ハチ・アイアンゴーレム・シロクマ・エンダーマン・ゾンビピグリンなど | 既存のターゲットと有効な怒りを引継ぎ、消失後に再捕捉 | モブごとの実際の怒りの発生・失効 |
| 通常のピグリン | 既存の敵対と `ANGRY_AT` を引継ぐ。新規敵対を一律には作らない | 金防具・ゾンビ系への回避・プレイヤー専用センサーを含む完全な新規捕捉の一致 |
| ウォーデン | 既存のターゲット・本人への怒りを引継ぐ。幽体からの振動を停止 | 本体への嗅覚・振動検知を含む新規捕捉 |
| クリーキング・エンダードラゴン | 既存のMobターゲットの切替経路は共通化。新たな敵対を強制しない | 視線・専用フェーズなどのPlayer専用処理との一致 |

すべてのモブの専用AIをプレイヤーと完全に同じにしたという検証結果ではない。通常のピグリンの新規センサー処理やウォーデン等の専用認識は引き続き実機確認が必要。設定の敵対補正無効時・範囲外は従来どおり補正しない。幼体ホグリンを一律に攻撃させない。

## 検証

Java 25 / Paper API `26.2.build.129-stable` でビルドと202件の自動テストを実施。既存機能の回帰テストに加えて、分類漏れ、再捕捉、怒り失効、他プレイヤーのターゲット維持、復帰時の引継ぎ、Brainの片側消失、変更イベントのキャンセル・変更、記憶の有効時間保持、スライム接触処理、幽体の振動停止を検証する。

使用するネイティブクラス・メソッド・フィールドはローカルのPaper `26.2.build.129-stable` 実装JARと照合済み。記号の照合はサーバーを起動しない検査であり、AIの実行試験ではない。Paper/Purpur上での実プレイ、クライアント接続、MyPet等との実サーバー併用は未検証。自動テストのモブはモックのため、実際の攻撃再開の確認は別途必要。
